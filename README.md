# Tic-Tac-Toe

A simple Tic-Tac-Toe game built with SwiftUI.

## About

This is a small iOS project created as a SwiftUI learning exercise.

The game allows you to play Tic-Tac-Toe against an AI opponent. The player controls X, while the AI plays as O.

The AI uses a simple decision-making system. It will take a winning move when available, block the player's winning move, prioritise the centre, and then choose available corners or sides.

## Current Status

Working.

The game currently supports:

- Human vs AI gameplay
- Win detection
- Draw detection
- Basic AI decision making
- Reset game button
- Simple SwiftUI interface

The project is still a work in progress and may be expanded with improved AI, animations, sounds and additional game features.
